# Third-party assets

Everything in this repository is the project's own work except the items
below. Each is vendored under `dashboard/vendor/` rather than fetched at
runtime — the board has to work when the school's network does not — so
each one also travels with the obligations listed here.

## dashboard/vendor/herzl.svg

Portrait of Theodor Herzl, used as the icon for **יום הרצל**.

- **Source:** <https://commons.wikimedia.org/wiki/File:Theodor-Herzl.svg>
- **Author:** AlkTheShadow
- **Licence:** [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)

This licence is **not** public domain, and two conditions come with it:

- **Attribution.** The author and licence must be credited wherever the
  work is redistributed. This file is that credit; the repository is
  public, so it travels with the asset.
- **Share-Alike.** The file itself, and any modified version of it, stays
  under CC BY-SA 4.0. Using it unchanged alongside this project's own
  code is an aggregation, not a derivative work, so it does not change
  the licence of anything else here — but a redrawn or edited version of
  the portrait would have to be released under CC BY-SA 4.0 too.

If those terms are ever unwelcome, the replacement is straightforward:
photographs of Herzl from his lifetime are long out of copyright, and a
fresh tracing of one would be the project's own work with no conditions
attached.

## dashboard/vendor/gveret-levin-hebrew.woff2

The **Gveret Levin** typeface, used for the school name (and now shown
only if the logo image fails to load).

- **Source:** <https://fonts.google.com/specimen/Gveret+Levin>
- **Licence:** SIL Open Font License 1.1

The OFL permits bundling and redistribution. Only the Hebrew subset is
vendored, at 11 KB.

## dashboard/vendor/papaparse.min.js

CSV parser, used to read the sheet's published feeds.

- **Source:** <https://www.papaparse.com/>
- **Licence:** MIT

## dashboard/vendor/school-logo.png

The school's own logo, supplied by the school. Not third-party in the
usual sense — but it is the school's mark, so it belongs to them and
should not be reused outside this board.
