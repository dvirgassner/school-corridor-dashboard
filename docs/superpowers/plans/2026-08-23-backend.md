# Backend Implementation Plan — School Corridor Dashboard

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the approved dashboard mockup to a Google Sheet backend with caching and demo mode, package the sheet as a one-click Apps Script template, and script the Raspberry Pi kiosk.

**Architecture:** The dashboard stays a static page (GitHub Pages). A `config.js` either points at four published-to-web CSV URLs (live mode) or is left null (demo mode → bundled sample data, clock pinned to 08:10). Pure data logic lives in `logic.js`, loadable both by the browser and by Node for tests. The Google Sheet is created by an Apps Script the school runs once. The Pi is provisioned by `pi/setup.sh`.

**Tech Stack:** Vanilla JS, PapaParse (vendored), Node ≥18 built-in `assert` for tests, Google Apps Script, Raspberry Pi OS Bookworm, cec-utils, Tailscale.

**Spec:** `docs/superpowers/specs/2026-08-22-school-corridor-dashboard-design.md`

## Global Constraints

- All Hebrew/RTL; grade columns data-driven from Schedule headers (6 or 7).
- Field length limits (spec §3): schedule subject 16, exam subject 12, exam room 12, event title 22, event location 12, normal msg 90, urgent msg 75, grade header 4.
- Message `Type` values (Hebrew in sheet): רגילה / דחופה / וידאו; `Active`: כן / לא. Code also accepts normal/urgent/video/yes.
- Dates: `YYYY-MM-DD` or `DD/MM/YYYY` or `DD.MM.YYYY`. Day letters: Sun=א … Fri=ו.
- Exam subjects display with the prefix `מבחן ב`.
- Screen hours: Sun–Thu 07:00–17:00, Fri 07:00–15:00.
- Refresh 60 s; stamp turns stale (amber) after 10 min; video plays once per 10 min while active, muted unless URL ends `#sound`.
- No frameworks, no build step. Tests run with `node tests/run.js`.

**Files:**

Test cases (`tests/run.js`, plain `assert`):
```js
assert.equal(L.toGematria(9), "ט׳");
assert.equal(L.toGematria(18), 'י"ח'.replace('"', "״"));
assert.equal(L.toGematria(15), "ט״ו");
assert.equal(L.toGematria(786), "תשפ״ו");
assert.equal(L.minutes("08:50"), 530);
assert.equal(L.parseSheetDate("2026-09-01"), "2026-09-01");
assert.equal(L.parseSheetDate("1/9/2026"), "2026-09-01");
assert.equal(L.parseSheetDate("01.09.2026"), "2026-09-01");
assert.equal(L.parseSheetDate("garbage"), null);
assert.ok(L.inRange("", "", "2026-09-01"));
assert.ok(L.inRange("2026-08-30", "2026-09-02", "2026-09-01"));
assert.ok(!L.inRange("2026-09-02", "", "2026-09-01"));
assert.ok(L.isActive("כן") && L.isActive("yes") && !L.isActive("לא") && !L.isActive(""));
assert.equal(L.normalizeType("דחופה"), "urgent");
assert.equal(L.normalizeType("וידאו"), "video");
assert.equal(L.normalizeType("רגילה"), "normal");
assert.equal(L.dayLetter(new Date(2026, 7, 23)), "א");   // Sunday
assert.equal(L.dayLetter(new Date(2026, 7, 22)), "ש");   // Saturday
```
Steps: write tests → run (fail) → implement → run (pass) → browser screenshot unchanged → commit.

### Task 3: Data-model builders (pure) with tests

**Files:**
- Modify: `dashboard/logic.js`, `tests/run.js`

**Interfaces (consumed by app.js in Task 5):**
- `buildSchedule(rows, fields)` → `{ grades: [names], byDay: { "א": [{period, start, end, subjects: {grade: subj}}] } }` — `fields` is PapaParse's ordered header list; grades = `fields.slice(4)`, rows filtered to valid `Start`/`End`.
- `buildAgenda(examRows, eventRows, todayKey)` → sorted array of `{kind:"exam", grade, subject, start, end, room}` | `{kind:"event", grades:[..], title, start, end, room}` (events' `Grades` split on `,`, trimmed; `Location` mapped to `room`). Malformed rows (bad date, missing start) skipped.
- `buildMessages(rows, todayKey)` → `{ normal: [text], urgent: [text], videos: [{url, sound}] }` (only active + in-range; `sound` true when URL ends `#sound`, suffix stripped).

Tests: one happy row per builder + one malformed row proving it is skipped, e.g. exam with `Date:"junk"` and event with empty `Start` are dropped; message with `Active:"לא"` excluded; video URL `"https://x/y.mp4#sound"` → `{url:"https://x/y.mp4", sound:true}`.
Steps: tests → fail → implement → pass → commit.

- Create: `dashboard/sample-data.js` — `window.SAMPLE = { scheduleCsv, examsCsv, eventsCsv, messagesCsv }` holding today's mock as CSV strings (dates written as `{{TODAY}}` and replaced at load so the demo always shows data).
- Modify: `dashboard/app.js`:
  - Delete MOCK_* constants and the 08:10 fallback pin (pin stays only when `sheets === null`).
  - `async function fetchAll()` — fetch 4 CSVs (`cache:"no-store"`, `&_=${Date.now()}` cache-bust), parse with `Papa.parse(text, {header:true, skipEmptyLines:true})`, build models via Task 3 builders, return `{model, fetchedAt}`; throw on any HTTP failure.
  - Cache: on success `localStorage.setItem("dash-cache", JSON.stringify({model, fetchedAt}))`; on failure fall back to cache; stamp shows `fetchedAt`, gets class `stale` when older than `staleMinutes`.
  - Demo mode: parse `SAMPLE` through the same pipeline; footer shows a muted "מצב הדגמה" badge.
  - Re-render only when the model JSON changed (preserves paging state); clock/highlight tick stays 5 s; data refresh every `refreshSeconds`.
- Test: screenshot demo mode (must look identical to today's board, plus badge); `node tests/run.js` still green. Commit.

### Task 8: Raspberry Pi kiosk package

**Files:**
- Create: `pi/setup.sh` — takes `DASH_URL` (+optional `HEALTHCHECK_URL`); apt-installs `chromium-browser cec-utils`; writes `~/kiosk.sh`; registers autostart for Wayfire (`~/.config/wayfire.ini` [autostart]), labwc (`~/.config/labwc/autostart`) and X11 LXDE (`~/.config/lxsession/LXDE-pi/autostart`) — whichever exists; installs cron.
- Create: `pi/kiosk.sh` — waits for network (`until curl -sf "$DASH_URL"; do sleep 3; done`), then `while true; do chromium-browser --kiosk --noerrdialogs --disable-infobars --incognito --check-for-update-interval=31536000 "$DASH_URL"; sleep 5; done` (loop = crash watchdog).
- Create: `pi/cron.txt` — CEC on `0 7 * * 0-4` and `0 7 * * 5`; standby `0 17 * * 0-4`, `0 15 * * 5` (via `echo "on 0" | cec-client -s -d 1` / `standby 0`); healthcheck curl `*/10 * * * *`; root reboot `0 3 * * *`.
- Create: `pi/README.md` — teen-readable walk-through: flash (Raspberry Pi Imager, hostname/Wi-Fi/SSH preset), first boot, `sudo raspi-config` autologin, run setup.sh, install Tailscale (`curl -fsSL https://tailscale.com/install.sh | sh`, `sudo tailscale up --ssh`), test power-cut recovery.
- Verify: `bash -n` syntax check each script; on-device verification is a deployment step. Commit.
